# Security Policy

## Supported Versions

Only the latest active release branch receives security updates.

| Version | Supported |
| :--- | :---: |
| v5.x |  Yes  |
| v4.x |  No   |
| < v4.0 |  No   |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you find a security bug inside the MUBIX Portfolio source codebase, please report it immediately:

1. **Do not** open a public issue.
2. Email your findings directly to **mubashir@mubix.in**.
3. Include detail on:
   - The nature of the vulnerability (e.g. CSRF, XSS, or package injection).
   - A step-by-step proof of concept (PoC) or script.
   - Possible patches or remediation ideas.

We will acknowledge receipt within 48 hours and attempt to provide a patch/remediation path within 7 days.
