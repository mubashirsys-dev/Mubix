# UI Components Directory

To maintain project build integrity and Vite compliance, the working React source code files reside under the standard source folder:

👉 **[src/components/](../src/components)**

## Component Catalog & Descriptions

- **[MubixOsLanding.jsx](../src/components/MubixOsLanding.jsx)**: Implements the full-screen browser-simulated desktop environment for MUBIX OS Lite.
- **[MubixPromptsShowcase.jsx](../src/components/MubixPromptsShowcase.jsx)**: Main dashboard for the AI Prompts compilation engine, containing scaled device mockups.
- **[BrutalCard.jsx](../src/components/BrutalCard.jsx)**: The central visual building block. Implements a neo-brutalist solid card border with colored box-shadows.
- **[NeoButton.jsx](../src/components/NeoButton.jsx)**: A tactile button featuring responsive active depression animations and custom styles.
- **[Chatbot.jsx](../src/components/Chatbot.jsx)**: Simulated client-side developer assistant with pre-programmed interactive flows.
- **[VisitorCounter.jsx](../src/components/VisitorCounter.jsx)**: Interface reading and writing to the counter API to track hits.
- **[ThemeToggle.jsx](../src/components/ThemeToggle.jsx)**: Triggering comic wipes and glitch transitions between Light and Cyber modes.
- **[LoadingScreen.jsx](../src/components/LoadingScreen.jsx)**: A terminal-based retro bootloader sequence showing hardware detection steps.
- **[ProfileCard.jsx](../src/components/ProfileCard.jsx)**: Hero profile layout summarizing studies, diploma scores, and branding details.
