# Changelog

All notable changes to the MUBIX Portfolio project are documented here. We adhere to Semantic Versioning.

---

## [5.0.0] - 2026-05-26
### Added
- Created a professional open-source repository structure with dedicated `assets/`, `docs/`, `components/`, `animations/`, `themes/`, and `chatbot/` layout maps.
- Added premium visual banner in `assets/` detailing the design system elements.
- Established continuous integration validation workflows (`build-validation.yml`) to guarantee compilation health.
- Added comprehensive community standards (`CONTRIBUTING.md`, `LICENSE`, `CODE_OF_CONDUCT.md`).

### Fixed
- Resolved esbuild regex syntax compiling issue in the AI Prompts Showcase component.

---

## [4.0.0] - 2026-05-24
### Added
- Integrated client-side **Interactive AI Chatbot** with custom response trees, typing animations, and scroll synchronization.
- Added dynamic, telemetry-guided **MUBIX Prompts Engine** showcase containing scaled device simulators.

---

## [3.0.0] - 2026-05-20
### Added
- Integrated **Cyberpunk Glitch Transitions** and theme-switching logic.
- Implemented Comic Wipe animation overlay for returning to standard light themes.

---

## [2.0.0] - 2026-05-15
### Added
- Refactored basic UI layout into a high-contrast **Neo-Brutalist Design System**.
- Configured heavy borders, flat offsets, and a warm cream theme.
- Integrated visitor telemetry tracking.

---

## [1.0.0] - 2026-05-01
### Added
- Initial basic portfolio template containing Hero role summaries, simple tools listings, and contact options.
